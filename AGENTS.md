## Workspace registration (AILAB)

When you work in a long-lived checkout of this repository on a machine or path that has no record in
`.ailab/workspaces/` yet (a new clone, a moved folder, a new PC), register it before you finish: add
`.ailab/workspaces/<machine>--<path>.usl.json`, a USL `usl-resource-graph/v1` record joining this
repository (`github:repo:1329527628`), the checkout path, the machine (hostname, OS, and how the
team reaches it: ssh alias, tailnet name or remote-desktop ID, login user) and the person who keeps
it with one `ailab:working-copy` link. Commit that file by itself and push it under this
repository's Git rules. Fill in what you can observe (hostname, path, OS) and ask the person for
access details instead of guessing. When the path changes, add a new record and set the old one's
`lifecycle` to `retired`; update `lastConfirmed` when you confirm one.

Never write a secret there: no password, key, token, remote-desktop password or credential-bearing
URL; name where one is kept in `secretRef`. This repository is public: record the machine, path and
person with `howToGetAccess` only, no addresses or login users.

Skip: delltower checkouts (observed automatically), temporary worktrees and scratch clones, CI
runners, and read-only inspection.

[WORKSPACE_REGISTRATION.md](https://github.com/airobotics-ailab/AILAB_DASHBOARD/blob/main/docs/WORKSPACE_REGISTRATION.md).
Generated by AILAB_DASHBOARD (bind.py agents); change it there, not here.
